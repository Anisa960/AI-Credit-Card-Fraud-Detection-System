\# 💳 AI Credit Card Fraud Detection System



A deep learning based fraud detection system that predicts whether a credit card transaction is normal or potentially fraudulent.



The project uses TensorFlow, Keras, SMOTE and Streamlit to build an end-to-end fraud analysis pipeline.



\---



\## 🚀 Features



✅ Deep Neural Network based fraud detection  

✅ Data leakage prevention  

✅ Training-only SMOTE balancing  

✅ Automatic fraud threshold selection  

✅ Fraud probability prediction  

✅ Individual transaction analysis  

✅ Complete CSV batch analysis  

✅ Fraud-only filtering  

✅ Downloadable prediction reports  

✅ Streamlit interactive dashboard
